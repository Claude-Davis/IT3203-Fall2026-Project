The Domain Naming System

The Domain Naming System (DNS), or “phonebook for the Internet”, is a component of the internet that converts human-friendly domain names into internet protocol (IP) addresses. DNS allows computers and servers to identify one another across the network, while providing users with easier names to remember when searching for particular sites or information.

The Domain Naming System (DNS) today started as an invention to solve the issue of rising costs as more people began to use the Internet. It has since become an essential part of the Internet protocol. DNS allows users to search for information by using human-friendly domain names and then converting those names into IP addresses stored on server databases. The client is then provided the requested file or an appropriate message in response. The DNS has become an essential part of the web experience for users of the Internet. Likewise,data privacy has also increased in importance for both workplace and casual Internet users. As a result, one of the DNS’s advancements has been to take on encryption methods that prevent external access to transactions between client and server.

Key Terms

Domain Name
A domain name is a human-readable web address. It is associated with a machine-readable IP address. A domain name consists of multiple parts; primarily the top-level domain, second-level domain, and the optional subdomain. Each part of the domain name works together to classify the purpose and origin of a website.
DNSSEC
DNSSEC, or Domain Name System Security Extensions, is a suite of security protocols. These protocols add cryptographic signatures to existing DNS records with intent to verify the identity and origin of DNS responses.
IP Address
"IP" in IP address stands for Internet Protocol. This address is a unique, numerical label that identifies a particular device or server on a network. The DNS translates human-readable domain names into these addresses.
Nameserver
A nameserver is a specialized server in the DNS. The purpose of this server is to translate between sites' domain name and IP address.
NS Record
An NS record, or name server record, responds to DNS queries by identifying which specific nameserver contains the IP address for a particular domain.
Paul Mockapetris
Paul Mockapetris is an American computer scientist and the inventor of the DNS.
DNS TTL
TTL, or Time to Live, is a number that specifies how much time, in seconds, the DNS resolver can wait before gathering the records for a website. The purpose of DNS TTL is to continuously update web content.
TLD
TLD stands for Top-Level Domain. It is the ending segment of a domain name and helps to categorize the origin, type, or purpose of a website.
