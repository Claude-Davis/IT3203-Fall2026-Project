Project Introduction

Project Overview
Milestone Objective Focus
#1 Build basic site with informational web pages on the chosen web technical topic. HTML and CSS (Modules 2, 3)
#2 Create a client-side quiz app for users to assess their learning of the topic. JavaScript and form processing (Modules 4, 5)
#3 Make the site responsive for screens of various sizes and complete research. Responsive web design, mobile web, and UX (Module 6)

This website is an applied learning project that requires the student construct a functional website using HTML, CSS, and JavaScript. The content of the website features the student's research of their chosen technical component of the World Wide Web.


Project General Requirements and Criteria

The general requirements for this project are as folllows:

  1. All site pages should have a consistent design and layout. The site should apply a simple, clean business style.
  2. Page style should be the student's own.
  3. No unapproved third-party frameworks, libraries, or templates should be used.
  4. The student should not use a tool to generate and copy code without first cleaning the code.
  5. All pages should function correctly on the hosted site.

The student's project grade is determined by the following:

  • The live site functions correctly.
  • The requirements specified in each milestone are met.
    • All required pages are present.
  • The code is well-informed and clean.
  • The research is accurate and of good quality.
  • The submission requirements are accurately followed.
