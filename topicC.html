Recursive DNS

Recursive DNS is the first step in locating an IP address. When a user requests a site in a browser, a DNS lookup, or DNS request, is sent to a recursive DNS server. The server will respond with either the IP information or by querying another server to obtain the information. Recursive DNS servers store information in their cache memory for quick access. The stored information are previous responses to DNS lookups. The data is stored for a certain amount of time referred to as time to live (TTL). The TTL is defined by the owner.

Authoritative DNS

Authoritative DNS servers contain a database of public IP addresses and their domain names. It stores the most up-to-date information compared to recursive servers. They respond to recursive servers’ requests if the recursive server does not have the needed information in its cache.
