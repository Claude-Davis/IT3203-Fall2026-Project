How DNS Works

The DNS process is initiated by a client’s request through the web browser. The client’s request, DNS lookup, first prompts the server to search its cache for the requested information. If the data is not there, the server sends the requests to other servers until the associated IP address is located. Once the address is located, the files are sent to the client machine.
